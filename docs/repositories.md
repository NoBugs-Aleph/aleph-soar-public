## 평가자 원본 확인

공개 문서는 로그인 없이 확인할 수 있습니다. 구현·원문 증적 검토가 필요한 평가자는
조장 김명준(GitHub `myeongjundev`)에게 GitHub 계정을 알려 주시면 해당 비공개
저장소의 읽기 권한을 별도로 조율합니다. 초대 후 평가자의 수락과 실제 열람 여부까지 확인합니다.

이 안내는 접근 절차이며, 특정 평가자에게 이미 초대·권한 부여가 완료됐다는 뜻은 아닙니다.
공개 저장소는 기존 소스와 커밋 이력을 미러링하지 않습니다.
