# 시연 장면과 증거를 읽는 방법

**현재 이 공개본에는 현장 화면 캡처·시연 영상·원문 로그를 게시하지 않았습니다.**
아래는 추가 자료를 정리할 때 사용할 장면별 기준입니다. 표 자체가 실행 증거는 아닙니다.
검토한 실제 자료가 확보되면 설명과 연결하고, 합성 화면을 쓰면 합성이라고 표시합니다.

| 장면 | 보여줄 자료 | 증명할 것 | 그 화면만으로 알 수 없는 것 |
| --- | --- | --- | --- |
| 정상 상태 | 민원포털 정상 업무·초기 차단 상태 | 시험 전 서비스와 대조 사용자 상태 | 공격 중 정상 사용자 영향 |
| 공격 입력 | 입력 횟수·출발지 구분·시각의 비식별 요약 | 합의된 입력이 실제 실행됨 | 관제 도착·탐지 |
| 수신·탐지 | Graylog 원문 대조·사건 | 원문 수신과 정의 발동을 각각 확인 | 실제 차단 효과 |
| 실제 대응 | n8n 실행과 대상 상태 | 실제 호출·적용 결과 | 사용자의 새 접근 결과 |
| 효과·정상 사용자 | 공격 거부와 정상 업무 대조 | 두 대상의 실제 영향 | 해제 뒤 복귀 |
| 티켓·원복 | 사건 상세·해제 기록·재접근·종료 | 조치·효과·해제·종료 연결 | 다른 사건이 같은 대상을 점유하는 모든 경우 |

## 한 사건으로 연결하기

- 장면마다 시험일·같은 실행의 익명 별칭·단계·관찰 시각을 붙입니다.
- 표시할 사건·요청·조치 별칭은 공개용이며 원본 식별자 대조표는 비공개로 보존합니다.
- 실제 시각과 사람이 화면을 관찰한 시각을 구분합니다.
- 캡처 한 장을 여러 케이스의 독립 성공 증거로 재사용하지 않습니다.
- 탐지·대응·효과·원복 시간은 각각 어떤 시점의 차이인지 적습니다.

## 게시 전 확인

키·토큰·쿠키·세션·QR·VPN 프로필·실제 계정·민원 내용·내부 주소·로컬 경로를 점검합니다.
화면 일부를 가려도 이해 가능한 설명을 붙이고, 숨긴 값으로 판정에 필요한 사실까지 사라지지 않는지 확인합니다.
출처·외부 자료 권리를 검토하고 팀이 공개할 자료 범위를 정한 뒤 게시합니다.

현재 실제 결과는 [S1 현장 기록 해설](s1-walkthrough.md)과 [검증 현황](verification.md)에 요약돼 있습니다.
