# 공개 범위와 갱신 기준

기존 비공개 저장소의 전체 이력을 가져오거나 공개 여부를 변경하지 않습니다.

포함하지 않는 것: 실제 비밀번호·키·토큰·쿠키·인증서, VPN 프로필·방화벽 설정 덤프,
내부 접속 주소·로컬 PC 경로, 원문 로그·DB·실제 계정, 팀 채팅·개인 메모·무검토 캡처.

원문 대조·실제 배포·효과·원복을 구분합니다. 전체 소스나 영상은 아직 이 공개본에 포함되지 않습니다.
추가 공개는 별도로 검토합니다. 라이선스와 외부 자료 권리를 확인하지 않은 파일은 복사하지 않습니다.
