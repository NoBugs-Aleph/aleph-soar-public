## S1 첫 보강 후 시험

- 10/28 S1-after-01에서 자동 차단 3건과 티켓, 정상 사용자 대조, 승인 후 실제 해제·최종 원복을 기록했습니다.
- 이는 **전체 시험 1회**입니다. 내부의 차단 3건을 독립 반복 N=3으로 세지 않습니다.
- 기록된 탐지 지연은 약 59.6초 / 53.4초 / 47.3초입니다. 소스 시계·측정 정의의 제약을 포함한 현장 기록이며 전 케이스의 성능 보장이 아닙니다.
- 해제는 사람 승인 후 임시 호출과 수동 released 기록을 포함합니다. 승인 해제 워크플로까지 전부 자동화됐다는 뜻은 아닙니다.
- 반복 시험, 같은 계정의 정상 출발지, 동시점 정상 재확인 등 추가 조건은 남아 있습니다.
